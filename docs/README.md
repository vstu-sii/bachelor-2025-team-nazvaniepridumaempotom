## AI Food Assistant
# 📌 Описание проекта
AI Food Assistant — «Помощник-шеф на основе ИИ», который предоставляет мгновенную объективную оценку приготовленного блюда. Пользователь загружает фотографию своего кулинарного творения и текстовый рецепт, а система на основе моделей компьютерного зрения (Llava) и языковой модели (Llama 3.2) анализирует внешний вид блюда и его соответствие рецепту, возвращая две оценки и конструктивные рекомендации. Помогает начинающим поварам и энтузиастам совершенствовать навыки, получать обратную связь и уверенно экспериментировать на кухне.

# ⚙️ Установка и запуск
Требования для локального запуска (текущий прототип):

Установить Python 3.11+

Установить Ollama и скачать модели:

bash
ollama pull llava:latest
ollama pull llama3.2:1b
Создать виртуальное окружение и установить зависимости:

bash
python -m venv .venv
source .venv/bin/activate  # для macOS / Linux
.venv\Scripts\activate     # для Windows
pip install -r requirements.txt
Запустить сервер:

bash
python main.py
Сервер будет доступен по адресу: http://127.0.0.1:8001/

План запуска (для будущего MVP):

Клонировать репозиторий проекта.

Запустить контейнеры через docker-compose up (планируется).

Открыть веб-интерфейс в браузере.

# 🛠️ Технологический стек — AI Food Assistant
Слой,	Технология,	Обоснование:
Frontend:	Next.js 14 + React (TypeScript)	Быстрая разработка интерактивного SPA с поддержкой загрузки файлов. SSR для SEO и производительности.
Backend (API):	FastAPI (Python)	Высокая производительность для IO-операций, автодокументация OpenAPI, простота интеграции с асинхронными задачами.
Backend (Бизнес-логика):	Python (Django/Flask планируется)	Мощный ORM для работы с профилями, рецептами, историей. Встроенная админ-панель.
База данных:	PostgreSQL (SQLite для MVP)	Надежная реляционная СУБД с поддержкой JSON для хранения структурированных данных.
Очереди/Кеш:	Redis (планируется)	Для организации очередей задач (Celery) и кеширования частых запросов (шаблоны ответов LLM).
AI Layer:	Ollama (Llava + Llama 3.2)	Локальный запуск моделей, приватность данных. Llava — анализ изображений, Llama 3.2 — анализ текста рецептов.
Инфраструктура:	Docker, Docker Compose	Контейнеризация для изоляции сервисов и простого развертывания.
## 🚀 MVP Scope — AI Food Assistant
Основные функции MVP:

Регистрация и авторизация пользователя.

Загрузка фотографии готового блюда и текстового рецепта.

# AI-анализ:

Оценка «Внешний вид (Вкусный вид)» по шкале 1-5 (через Llava).

Оценка «Соответствие рецепту» по шкале 1-5 (через Llama 3.2).

Генерация текстовой обратной связи и рекомендаций.

Сохранение и просмотр истории оценок.

Базовый личный кабинет с отображением статистики (средние оценки, прогресс).

# 📈 Метрики успеха продукта
Технические метрики
Среднее время отклика API (кроме анализа): ≤ 500 мс.

Время полного AI-анализа (от загрузки до результата): ≤ 15 секунд.

Доступность системы (в рабочее время): ≥ 99%.

Процент успешных AI-запросов: ≥ 90%.

Время загрузки страницы интерфейса: ≤ 2 секунд.

# Пользовательские метрики (Целевые для MVP)
North Star Metric: >75% пользователей, получивших оценку, согласны с ней и считают её полезной (опрос через 3 дня).

Удовлетворённость тестовых пользователей: ≥ 70%.

Retention на 7-й день: ≥ 30%.

Количество проведённых оценок на активного пользователя в неделю: ≥ 2.

Процент пользователей, вернувшихся для второй оценки: ≥ 40%.

# AI-метрики
Согласованность оценок модели: Оценки не должны быть случайными, а основываться на входных данных.

Качество текстовой обратной связи: Рекомендации должны быть конкретными и выполнимыми (проверяется модератором).

Успешность распознавания блюда на фото: ≥ 80% (для типичных, хорошо сфотографированных блюд).

Стабильность работы AI-пайплайна: Отсутствие критических сбоев при обработке 95% запросов.
